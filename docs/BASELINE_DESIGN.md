# 青光眼分类基线设计

设计日期：2026-10-16。状态：B0/B1 工程实现位于 `src/glaucoma`，正式数据训练尚未启动。运行方式见项目 README。

## 1. 目标与实验边界

建立可复现的图像分类基线，测量年龄的增量价值，并完成验证、模型保存和提交文件生成流程。主指标为 AUROC。

第一轮只运行两个实验，使用相同数据、随机种子、图像处理、优化器和损失设置：

| 编号 | 输入 | 模型 | 用途 |
|---|---|---|---|
| B0 | 完整眼底图 | ConvNeXt-Tiny + 分类头 | 图像基线 |
| B1 | 完整眼底图、年龄及其状态标记 | ConvNeXt-Tiny + 年龄 MLP + 分类头 | 测量年龄融合收益 |

两者使用随机初始化，`weights=None`。官网允许预训练权重的范围尚不明确，第一轮不依赖外部权重或数据。视盘定位、局部图、基础模型、自监督预训练和集成留作后续独立实验。

训练只使用 train。valid 用于模型选择和评估。test 只用于最终推理，不参与预处理统计量拟合、自监督训练或伪标签训练。

## 3. 数据处理

### 图片

1. 根据目录建立大小写无关的文件名映射；映射不唯一或图片缺失时明确报错。
2. 读取图片、应用 EXIF 方向并转换为 RGB。
3. 等比缩放至最长边 384，居中补黑边至 `384 × 384`，保留完整视野。
4. 训练增强：水平翻转概率 0.5；旋转范围 ±10°；温和颜色扰动，亮度/对比度 0.15、饱和度 0.10、色相 0.02。旋转填充值为黑色。
5. 转为 `[0, 1]` 浮点值，各通道使用 `mean=0.5, std=0.5` 归一化。

验证和测试使用相同的确定性缩放、补边及归一化。第一轮单视图推理。

训练前逐张检查解码可用性；损坏文件要记录并报告，不能静默丢弃。跨集合重复检查应记录证据，发现重叠时先评估其对验证可信度的影响，不自动修改官方划分。

### 年龄

预先固定规则：缺失或非有限值记为 missing；有限值中 `age <= 0` 或 `age > 100` 记为 invalid。这是本基线的异常值处理约定，不代表医学上年龄大于 100 必然错误。

仅用训练集有效年龄计算中位数、均值和标准差。异常值和缺失值用该中位数填补，标准化后得到 `age_z`。B1 输入为 `[age_z, is_missing, is_invalid]`。保存处理统计量，验证和测试复用；不根据验证标签修改清洗规则。

## 4. 模型结构

使用当前环境的 `torchvision.models.convnext_tiny(weights=None)`，保留特征提取器、全局平均池化及末端 LayerNorm，得到 768 维图像特征。两个实验保持相同的骨干网络初始化。

**B0：** 图像特征 768 → Linear(768, 128) → GELU → Dropout(0.2) → Linear(128, 1)。

**B1：** 年龄输入 3 → Linear(3, 16) → GELU → Linear(16, 8)；与图像特征拼接为 776 维，再经 Linear(776, 128) → GELU → Dropout(0.2) → Linear(128, 1)。

训练时输出一个 logit，直接计算 BCEWithLogitsLoss；推理时取 sigmoid，得到阳性概率。无需安装 timm 即可实现这两个基线。

## 5. 固定训练配置

以下参数是第一轮起点，尚未通过训练验证其效果或显存占用。

| 参数 | 固定值 |
|---|---|
| 输入尺寸 | 384 × 384 |
| 初始化 | 随机初始化，外部权重为空 |
| 种子 | 42 |
| 损失 | BCEWithLogitsLoss，`pos_weight=5`，按批次样本数取均值 |
| 采样 | 保留原始类别分布，每轮打乱；不额外过采样 |
| 优化器 | AdamW |
| 学习率 | 3e-4 |
| 权重衰减 | 0.05；bias 和归一化参数不衰减 |
| 训练长度 | 60 epochs |
| 学习率调度 | 前 5 epochs 线性 warmup，再余弦衰减至 1e-6 |
| 单卡 micro batch | 16，启动时实测显存 |
| 梯度累积 | 4 次，有效 batch 为 64 |
| 精度 | FP16 autocast + GradScaler |
| 梯度裁剪 | 全局范数 1.0，在 unscale 后执行 |
| DataLoader | 起始 workers=4，pin_memory=True |
| 验证 | 每个 epoch 完整评估 valid |
| 模型选择 | 验证 AUROC 最大；完全相同时比较 AUPRC |

`pos_weight=5` 是温和加权的工程起点，不是已验证最优值。先固定它测量年龄的贡献；之后可用普通 BCE 做损失对照。

两个实验均运行完整 60 epochs，并保留验证表现最佳的 checkpoint。梯度累积需正确处理最后一个不完整窗口，学习率按实际优化器步数更新。若 batch=16 显存不足，改为 batch=8、累积 8 次，保持有效 batch=64，并记录配置变化。

V100 使用 FP16。先在 GPU 0、1 分别运行 B0、B1；实际启动前重新检查占用。第一轮不依赖多卡通信。后续需要 DDP 时沿用已验证的 `NCCL_P2P_DISABLE=1`，并实测吞吐。

## 6. 评估与输出

每轮记录训练损失、验证损失、AUROC、PR 曲线梯形面积 `auprc_trapz`、Average Precision `AP`，以及阈值 0.5 下的混淆矩阵。AP 与梯形面积分别命名，不能混用；最终对齐官方 AUPRC 实现。

辅助报告特异度至少 95% 时的敏感度，并明确阈值来自验证集。其用于观察漏诊情况，不替代官方排名指标。加权 BCE 的 sigmoid 输出不应自动视为已校准风险。

B0、B1 使用相同验证集，报告整体和年龄分层结果。验证阳性只有 191 例，单次微小涨分不能直接认定有效；出现有希望的增益后，再使用相同的额外种子复验，并计算配对 bootstrap 差值区间。有患者 ID 时应按患者重采样；当前只能按图片评估，需保留这一局限。

每次运行使用唯一目录，例如 `outputs/baseline/b0_image/seed42_<run_id>/`，至少保存：

- 完整配置、依赖版本、代码版本、CSV 校验值和随机种子。
- 年龄预处理统计量（B1）、训练日志、逐轮指标及最佳 epoch。
- 最佳推理权重；断点恢复 checkpoint 单独存放，不混入部署文件。
- 验证预测表：图片名、真实标签、logit、概率。
- 最终推理时生成 `submission.csv`，UTF-8，列为 `Image_name,Probability,Pred_Label`；保持 test.csv 中的原始名称和顺序，共 5,855 行，默认以 0.5 生成类别。

部署验收需要在 T4 上检查 batch=1 的完整流程，包括图片解码、预处理、前向和后处理。记录耗时分布及模型总大小；V100 上的测试不能替代 T4 验收。

## 7. 实现顺序与基线交付

1. 完成数据读取、年龄处理、模型和评估模块，先核验样本对应关系、输出形状、概率范围与保存/加载一致性。
2. 用少量训练样本验证模型能够降低损失，确认累积梯度及 FP16 路径正常。该结果只用于排错。
3. 运行一个 epoch 的完整流程检查，确认全量读取、验证、日志和 checkpoint 均可用；正式实验从相同随机初始化重新开始。
4. 完成 B0、B1 正式实验，提交指标对照、最佳模型、验证预测和推理入口。
5. 根据结果决定下一项单因素实验：分辨率、损失加权或可靠的视盘局部图。预训练方案须先明确规则。

基线不预设可达到的 AUROC。当前已有的 0.695718 仅是年龄排序参考值，图像模型和融合模型的指标均待实测。
